---

## 2️⃣ Install (5 minutes - one time only)

Open Command Prompt in this folder:

```bash
npm install --legacy-peer-deps
```

Wait for it to finish (grab coffee ☕)

---

## 3️⃣ Run (30 seconds)

```bash
npm run dev
```

Open browser: **http://localhost:3000**

---

## 4️⃣ Personalize (3 minutes)

Open `config/content.ts` and change:

- Memory descriptions (line 15-50)
- Photo captions (line 55-95)
- Birthday letter (line 110-130)

---

## 5️⃣ Test

- ✅ Photos show up?
- ✅ Countdown shows October 10?
- ✅ Everything looks good?

---

## 6️⃣ Deploy (5 minutes)

```bash
npm install -g vercel
vercel login
vercel
```

Get your URL → Share with Roqeebat on Oct 10! 🎉

## 🆘 Having Issues?

**Photos not showing?**
- Check file names: EXACTLY `memory1.jpg`, `photo1.jpg` etc.
- No spaces, no capitals in wrong places

**Install taking forever?**
- Normal! First time takes 5-10 minutes
- Let it finish

**Need help?**
- Read: `STEP-BY-STEP-SETUP.md` (detailed version)
- Check: `HOW-TO-ADD-PHOTOS-AND-VIDEOS.md` (photo guide)
