```

│   ├── images/
│   │   ├── memory1.jpg to memory4.jpg    ← 4 photos

│   │       └── photo1.jpg to photo9.jpg  ← 9+ photos

└── config/
    └── content.ts  ← Your stories, messages, letter
```
