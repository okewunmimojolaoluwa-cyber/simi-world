## 🆘 Troubleshooting Checklist

If something's wrong:

### Photos Not Showing
- [ ] Check file names (EXACTLY: memory1.jpg, photo1.jpg)
- [ ] Check they're in right folders
- [ ] Refresh browser (Ctrl + Shift + R)
- [ ] Check file extensions (.jpg not .jpeg or .JPG)

### Install Issues
- [ ] Try: `npm install --legacy-peer-deps --force`
- [ ] Delete node_modules folder
- [ ] Try again
- [ ] Check internet connection

### Site Won't Start
- [ ] Check if port 3000 is in use
- [ ] Try: `npm run dev -- -p 3001`
- [ ] Restart computer
- [ ] Try again

### Video Not Playing
- [ ] Check it's MP4 format
- [ ] Check file size (under 50MB)
- [ ] Try different video
- [ ] Test in different browser

### Deploy Failed
- [ ] Check internet connection
- [ ] Run: `npm run build` first
- [ ] Fix any errors shown
- [ ] Try: `vercel` again
