## 🆘 Need Help?

**Something not working?**
1. Check `STEP-BY-STEP-SETUP.md` (troubleshooting section)
2. Make sure file names are EXACTLY right (case-sensitive!)
3. Try refreshing browser: Ctrl + Shift + R
4. Make sure photos are .jpg format

**Common issues:**
- Photos not showing → Check file names
- Install stuck → Be patient, first time takes 5-10 min
- Port in use → Use: `npm run dev -- -p 3001`
